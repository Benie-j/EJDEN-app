Google Drive

Une copie de toutes vos données est envoyée dans un espace privé de votre Drive, que seul EJDEN peut lire.

Configuration Google

Collez l'identifiant client OAuth (type « Application Web ») créé dans Google Cloud Console, API Google Drive activée.

Fichier de sauvegarde

Enregistrez la copie sur le téléphone ou envoyez-la vers Google Drive, WhatsApp ou un e-mail avec le menu de partage.

Restaurer cette sauvegarde ?

Les données actuelles de l'appareil seront remplacées. Sauvegardez-les d'abord si besoin.
